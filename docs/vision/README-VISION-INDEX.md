# README — LifeOS vision corpus (index only)

This folder preserves the long-horizon product vision. It is strategic input, not implementation authority: `docs/REQUIREMENTS.md` and ADRs govern builds, and vision ideas enter implementation only through reviewed contract changes (ADR 0005 governs that path). Repo doctrine outranks this folder wherever they conflict — flag conflicts, never resolve them.

**This index carries no status claims.** Earlier versions tracked per-plan progress here and every claim rotted. Current truth: `docs/PROJECT_STATE.md` → `docs/program/`. Build-plan files live in `docs/implementation-planning/` and carry their own STATUS headers.

## Contents

**The vision passes (reading order):**

- `vision-fable-final-pass.md` — pass 1: features (Initiative Ladder, Triggers, Compost, Mirror, Moments×Map, Rehearsal, Life Archive, apparatus sunset). One-glance map: `vision-fable-final-pass-map.html`.
- `vision-fable-deeper-pass.md` — pass 2: layers (profile-as-hypothesis, rupture protocol, trust kernel, sanctuary, delight budget, inference ladder, and more).
- `vision-fable-wider-pass.md` — pass 3: world (agentic perimeter + injection invariant, second dyad, sibling harvest, operator-only boundary).
- `vision-fable-horizon-pass.md` — pass 4: seams (purpose gauge, council view, cadence stack + closure ritual, gardens, future self).
- `vision-execution-companion.md` — curated candidate contracts per vision item (WHAT/LANDS/WHEN/SPEC/DONE-WHEN/NEVER). Use to prepare requirements and issues, never as standalone build authority.

**THE METHOD (domain-general, not LifeOS-specific):**

- `THE-METHOD-self-sustaining-systems.md` — the doctrine (6 layers, 15 axioms, phases 0-5).
- `THE-METHOD-companion-templates.md` — templates T1-T9 + phase-exit checklists.

**Prototypes:** `prototypes/` — throwaway UX prototypes; taste reference only, never import.

## Standing rule

Do not bulk-create issues from this folder. Review candidates one by one against current doctrine, then open only the next owner-approved, bounded slices.
