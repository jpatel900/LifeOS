# Codex prompt template

For a manual Codex run. AGENTS.md governs; the issue body is the contract.

Goal · Mode (implement / review / plan only) · Authority (requirement, ADR, invariant) · Acceptance criteria (checkable) · Risky surfaces (AGENTS.md "Owner gates", or none) · Proof (the command or browser check that shows it works; what must not change) · Report (what changed, commands + output, UNVERIFIED, rollback).
